# ❄️ ICEGODS SOLANA GATEKEEPER v2.0
Professional-grade Telegram subscription bot with automated Solana payment verification.

### 🚀 Features
- **Automated SOL Payments:** Real-time verification via Helius RPC.
- **Member Management:** Auto-generates unique invite links.
- **Database Integrated:** Uses Supabase/PostgreSQL to track expiry.
- **Render Ready:** Optimized for cloud deployment.

### 💰 Monetization
Set your price in `main.py` and start collecting revenue directly to your wallet.
